# RPi 4 Smart AI Vision Suite (4GB RAM & 5V/2A Eco-Power Edition)

مشروع ذكاء اصطناعي ورؤية حاسوبية (Computer Vision) متكامل ومُصمم خصيصاً ليعمل بأعلى كفاءة وأقل استهلاك للطاقة والرامات على **Raspberry Pi 4 (4GB RAM)** مع كاميرا **Raspberry Pi Camera Module V2** وشاحن **5V 2A**، ويعمل أيضاً مباشرة على كاميرا اللابتوب للتجربة والتطوير.

## المميزات (4 مشاريع AI في تطبيق واحد!)
يمكنك التبديل بين الـ 4 أوضاع لايف أثناء تشغيل الكاميرا بالضغط على الأرقام من الكيبورد:
- **`[1]` كاشف الوجوه والعيون والابتسامة بالذكاء الاصطناعي (ResNet-10 SSD DNN):** يكتشف الوجه بدقة عالية حتى مع ميل الرأس أو النظارة، ويحدد العيون وحالة الابتسامة أو التركيز.
- **`[2]` نظام التعرف على صاحب الجهاز (Smart Face ID):** اضغط حرف **`[R]`** وأنت تنظر للكاميرا ليحفظ ملامح وجهك في ثانية واحدة، ويميزك باللون الأخضر (`Ahmed (Owner)`) مقابل أي شخص غريب (`Unknown Person`).
- **`[3]` كاشف الأجسام وعدّاد الأشخاص (MobileNet-SSD 20 Classes):** يكتشف 20 نوعاً من الأجسام في الغرفة (أشخاص، زجاجة، كرسي، شاشة، قطة، إلخ).
- **`[4]` الحارس الذكي ومنطقة الإنذار (Smart Security Guard Zone):** يحدد منطقة محمية على الشاشة، وعند دخول أي شخص أو حركة بداخلها يطلق إنذاراً مرئياً ويحفظ صورة تلقائياً في مجلد `snapshots/`.

## حماية خاصة لشاحن 5V 2A ورامات 4GB
- **استهلاك الرامات (المقاس فعلياً):** حوالي **173 ~ 190 MB** للتطبيق (`VmRSS`) من أصل 4096 MB (أقل من 5% من الرامات)، وحجم المشروع بالموديلات على الكارت **56 MB** فقط.
- **حماية الباور (2 أمبير):** الكود يحدد استهلاك OpenCV/BLAS على نواتين فقط (`cv2.setNumThreads(2)`) مع دقة `640x480` و`20 FPS` وخاصية `Eco Frame-Skip` لتخفيف سحب التيار، ويراقب حساس الفولت والحرارة في الراسبيري باي (`vcgencmd get_throttled`) لحظياً.

## 1. التشغيل على اللابتوب الآن
```bash
cd ~/rpi4_smart_vision
./run_laptop.sh
```

## 2. التشغيل على Raspberry Pi 4
```bash
git clone <YOUR_GITHUB_REPO_URL>
cd rpi4_smart_vision
chmod +x setup_rpi.sh
./setup_rpi.sh
python3 app.py
```
